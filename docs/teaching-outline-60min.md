# AIAgent 60 分鐘教學大綱

> 對象：具備 C#／.NET 基礎的開發者｜形式：概念講解＋簡短示範｜時間：55 分鐘教學＋5 分鐘問答

## 1. 教學方向與學習目標

以「一個小型程式修改任務」貫穿全場，帶聽眾理解 Agent 如何探索專案、規劃工作、呼叫工具、修改與驗證。各項功能依任務流程串接，詳細實作可在後續課程展開。

聽眾在課後應能：

- 說明 CLI、Core、Llm、Tools、Workspace 的分工，以及模型與工具之間的循環。
- 區分計畫確認、單次操作核准與完成證據，理解操作權限如何由程式落實。
- 知道長任務、外部文件、多模型與多 Agent 能力適合用在什麼地方。

專案背景見 [README](../README.md)、[總規格](../SPEC.md) 與 [ROADMAP](../ROADMAP.md)；目前功能及分層驗證狀態以 README 為準。

## 2. 60 分鐘時間安排

| 時間 | 主題 | 講解方向 |
|---|---|---|
| 0–5 分鐘 | 專案定位與成果展示 | 說明 AIAgent 解決的問題，展示範例修改前後的成果；簡介終端機輸入、安全預覽與進度顯示。 |
| 5–13 分鐘 | Agent 的核心架構 | 介紹五個主要模組；畫出「使用者需求 → 模型 → 工具呼叫 → 程式檢查與執行 → 結果回傳模型 → 回答」的循環，點出取消與預算的停止條件。 |
| 13–23 分鐘 | 讓 Agent 理解專案 | 示範搜尋與局部讀檔；說明 Context、摘要與預算的用途，以及 AGENTS.md 提供專案慣例、Skills 提供可重用流程。 |
| 23–38 分鐘 | 從規劃走到修改 | 以同一任務串起 Plan／Execute、任務清單、完整讀檔、差異預覽、逐次核准與寫入結果。這 15 分鐘是教學重點。 |
| 38–48 分鐘 | 如何確認結果與接續工作 | 展示受控建置、Git 差異與唯讀審查；簡介檢查點復原，以及工作保存與續接的用途。 |
| 48–55 分鐘 | 進階能力如何擴充 | 介紹 MCP 與 Microsoft Learn 文件查詢、多模型切換、唯讀多 Agent 分工；每項只交代用途、流程位置與一個例子。 |
| 55–60 分鐘 | 重點回顧與問答 | 回顧完整任務流程，確認聽眾能區分模型建議、實際操作與驗證結果，提供後續閱讀方向。 |

## 3. 共同案例與示範主線

備課時準備一個小型 .NET Console 專案，包含既有的 `GetGreeting(name)` 函式。任務是讓空字串或純空白名稱回傳「你好，訪客」，一般名稱維持原行為。使用同一案例貫穿課程，避免切換情境占用時間。

1. **探索專案**：由需求找出函式所在位置，展示搜尋與局部讀取如何縮小範圍。
2. **形成計畫**：進入 Plan，列出修改與建置驗證步驟；讓聽眾看懂預計做什麼，以及完成的判定方式。
3. **確認並修改**：切換 Execute、確認目前計畫，送出新的執行指示；重新完整讀檔建立修改基準，檢視差異並逐次核准寫入。計畫確認與單次操作核准分別處理。
4. **驗證並檢視差異**：另行核准受控 Debug 建置，檢視實際退出結果與 Git 差異。建置成功只證明該次目標可建置；函式行為仍需另行驗證，審查結果則提供問題分析。
5. **介紹後續選擇**：需要撤回修改時介紹檢查點；隔日接續時介紹工作保存。前者處理受控檔案修改的復原，後者保留工作背景與待辦，續接時須重新核對狀態與授權。

核心程式碼只挑以下三處，各看一小段責任與資料流：

- [AgentRunner](../src/AIAgent.Cli/Core/AgentRunner.cs)：模型呼叫、工具循環與停止條件。
- [ITool 與工具契約](../src/AIAgent.Cli/Tools/ToolContracts.cs)：工具如何描述、接收參數與回傳結果。
- [FileChangeApprovalBridge](../src/AIAgent.Cli/Core/FileChangeApprovalBridge.cs)：寫入預覽與使用者核准的銜接。

## 5. 講授取捨與備課提醒

- **時間優先順序**：保留核心循環、規劃、核准與建置示範；時間吃緊時，以預先準備的結果帶過進階能力，保留最後 5 分鐘問答。
- **示範準備**：事先確認範例可建置，備好修改前後差異與操作結果截圖；主線只做一次小修改。復原、保存及外部查詢以概念或既有結果說明。
- **目前支援範圍**：產品內的 `test` 目前不支援，本次驗證示範採受控建置。MCP／文件擷取以固定 Microsoft Learn 來源介紹；多模型採明確切換；多 Agent 為明確啟用、同模型、每批至多兩個唯讀子任務。
- **安全觀念隨流程說明**：認證資料僅經隱藏輸入；讀寫受工作區限制；規則、技能、外部文件與子 Agent 結果都不能自行授權操作。
- **後續再展開**：逐字稿、完整指令手冊、供應商協定、程序隔離與各模組詳細實作，留待有需求時另行整理。
